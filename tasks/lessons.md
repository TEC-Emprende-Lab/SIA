# Lecciones

## Fidelidad visual del mockup — 2026-09-28

- Una estructura funcional inspirada en el mockup no basta cuando se solicita trasladar
  su UI: comparar primero la jerarquía, densidad, navegación, tipografía, iconografía y
  superficies renderizadas antes de declarar el corte visual como cercano.
- Reutilizar las reglas y los datos reales no obliga a conservar la composición del
  frontend previo. La implementación debe separar el contrato de datos de la referencia
  visual y adoptar esta última de forma explícita.
