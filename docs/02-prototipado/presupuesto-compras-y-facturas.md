# Presupuesto, compras y facturas de Prototipado

## Presupuesto por partidas

El presupuesto se organiza en partidas aprobadas y muestra monto asignado, ejecutado, disponible y porcentaje consumido. Las compras y facturas descuentan la partida correspondiente. Los cambios presupuestarios requieren revision o aprobacion y conservan trazabilidad.

El emprendimiento puede consultar su ejecucion financiera para controlar el presupuesto. La lista oficial de partidas y las reglas para mover fondos entre ellas estan `TBD`.

## Compras y facturas

El flujo contempla solicitud, cotizacion, revision, factura y pago. Debe evitar una carga duplicada de la factura entre plataformas. El flujo exacto, responsables, estados, sistema administrativo y viabilidad de integracion estan `TBD`.

No se aprueba automaticamente una compra ni un cambio presupuestario mediante IA.
