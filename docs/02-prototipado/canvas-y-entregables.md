# Canvas y entregables de Prototipado

El canvas de Prototipado organiza las areas y entregables de desarrollo, prueba, validacion y pilotaje. Cada entregable se desagrega en objetivos, actividades y evidencias; un tema amplio no puede marcarse como completado sin ese desglose.

Las areas oficiales, definicion de cada entregable, obligatoriedad, condiciones por tipo de emprendimiento y formato de evidencia estan `TBD`. La version del canvas debe conservarse en el expediente para permitir comparar la evolucion entre momentos.
