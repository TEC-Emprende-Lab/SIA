# Historias de usuario de Prototipado

## US-PRO-001 - Registrar avance del entregable

Como Emprendedor, quiero registrar objetivos, actividades, fechas y evidencias de un entregable de Prototipado para mostrar el avance verificable de mi solucion.

**Aceptacion:** el registro pertenece al emprendimiento autorizado, se desagrega en actividades y puede visualizarse en el cronograma.

## US-PRO-002 - Validar hito de Prototipado

Como Gestor asignado, quiero validar o devolver un hito para confirmar que el entregable cumple la evidencia requerida.

**Aceptacion:** la decision registra actor, fecha y observacion; un objetivo aprobado modificado vuelve a validacion.

## US-PRO-003 - Consultar presupuesto por partida

Como Emprendedor, quiero consultar el monto asignado, ejecutado, disponible y porcentaje consumido por partida para controlar mi ejecucion financiera.

**Aceptacion:** compras y facturas autorizadas afectan la partida correspondiente y no se duplican por la carga administrativa.

## US-PRO-004 - Preparar informe mensual

Como Gestor, quiero preparar un informe mensual desde avances, evidencias, minutas, acuerdos y finanzas para comunicar el estado del programa con fuentes trazables.

**Aceptacion:** el informe es un borrador antes de aprobarse y sus fuentes y version aprobada son inmutables.
