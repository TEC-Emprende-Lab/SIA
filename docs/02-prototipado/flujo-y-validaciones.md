# Flujo y validaciones de Prototipado

1. El Gestor y el emprendimiento trabajan sobre el canvas y definen entregables desagregados.
2. El emprendimiento registra objetivos, actividades, fechas y evidencias.
3. Las actividades alimentan el cronograma o calendario.
4. El emprendimiento presenta un hito o entregable para validacion.
5. Un Gestor asignado o Coordinadora valida, solicita correccion o rechaza, conservando actor, fecha y observacion.
6. La validacion puede habilitar el siguiente entregable o bloque cuando la definicion oficial lo establezca.

Los estados exactos, criterios de aprobacion y automatizaciones estan `TBD`. Los objetivos aprobados que cambien requieren una nueva validacion.
